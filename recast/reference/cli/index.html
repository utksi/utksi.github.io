    Command line¶

    recast SUBCOMMAND [options]; recast SUBCOMMAND --help prints the options of each.

    recast correct¶

    Correct one structure with the released networks (recast.correction.correct).

    Option Meaning
    STRUCTURE calculated structure: POSCAR, CIF or any file ASE reads
    --source dft (default), tece_oam_rra or equflashv2_oam: what relaxed the structure
    --functional PBE (default) or PBE+U, for a DFT structure
    --given FILE place the atoms also at this cell: JSON {"cell": ...} or a Green-Lagrange {"strain": ...}, or a structure file
    --symmetrize TOL project the correction onto the input's space group at TOL angstrom
    -o, --out output folder
    --release DIR local release folder (default: download utksi/recast-models)
    --mace FILE mace-omat-0-medium.model (default: download)
    --workdir DIR keep the computed features in this folder
    --inputs SPEC featurizers: shipped (default, every input from MACE-OMAT-0), toy, or MODULE:FUNCTION for a release trained with your own
    --threads N PyTorch threads (0: PyTorch's default)

    Pipeline¶

    Subcommand Options Function
    recast toy -o, --out recast.toy.write_toy_pairs
    recast targets PAIRS, -o, --out recast.pipeline.make_targets
    recast features TARGETS, -o, --out, --inputs, --mace, --device, --shard I/N, --resume; or --merge SHARD ... recast.pipeline.write_training_folder, recast.pipeline.merge_training_folders
    recast members --data, --partitions, --keys, --runs, --seeds, --presets, --device, then -- and recast train options recast.pipeline.train_members
    recast jobs --data, --partitions, --keys, --runs, --seeds, --presets, --device, --command, -o, --out, --sbatch, --account, --partition, --time, --cpus, --gpus, --mem, --setup, --name, then -- and recast train options recast.pipeline.job_lines, recast.pipeline.slurm_script
    recast select RUN ..., --data, --keys, --metric recast.pipeline.select
    recast export --runs, --keys, --data, --name, -o, --out recast.pipeline.export_release
    recast evaluate --release, --data, --partitions, --keys, -o, --out recast.pipeline.score_release

    recast features --shard I/N computes the structures of index i with i mod N = I (in the sorted order of the structure keys) into its own folder, which is a training folder of those structures; --resume continues an interrupted run in the same folder; --merge joins the finished shard folders into the folder of one run. recast jobs writes one recast train line per member type, seed and key (and, with --sbatch, a Slurm array script that runs line SLURM_ARRAY_TASK_ID + 1); it never submits anything. Lines of one run folder may run at the same time: each writes only the files of its key.

    Partitions¶

    Subcommand Options Function
    recast groups DATA, -o, --out recast.partitions.group_table
    recast split DATA, -o, --out, --keys, --test, --val, --order, --units recast.partitions.test_splits
    recast folds --partitions, --keys, --groups, -o, --out, --random, --formula, --prototype, --seed, --units, --add-to recast.partitions.development_folds, recast.partitions.add_families
    recast grouped DATA, --groups, -o, --out, --prototype, --chemsys, --units recast.partitions.grouped_folds
    recast fraction PARTITIONS, -o, --out, --fraction, --seed, --keys recast.partitions.fraction
    recast table --splits, --split-keys, --folds, --fold-keys, --id-name, --columns, -o, --out recast.partitions.write_table

    --units FILE (a CSV with columns key,unit) keeps the pairs of one unit on one side of every partition, for example several experimental reports of one material. --order FILE lists the pairs in the order that defines the permutation of recast split (default: the sorted keys). recast folds draws the development folds inside the pairs that are in no test set of --partitions; the families are drawn in the order random, formula, prototype with one generator.

    Modules with their own options¶

    recast train, recast predict and recast score run recast.train, recast.predict and recast.score with their own options: one member type (--preset) and any of its hyperparameters; the predictions of a release for a features folder; the scores of a member's test predictions.
