    Python API¶

    Every module opens with the mathematics it implements; every function states its equation in the comment above it and its inputs and outputs in its docstring. The modules in pipeline order:

    recast.correction ¶

    SPDX-License-Identifier: MIT Utkarsh Singh: github.com/utksi

    One call from a calculated crystal structure to the corrected one: read the structure, fetch the models, compute the inputs (recast.featurizers: MACE-OMAT-0 descriptors, Green-Lagrange Hessian and D3 relaxations), apply the released networks (recast.predict) and write the corrected structure with a summary. The command recast correct (recast.cli) and recast.correct call correct().

    Mathematics (recast.predict; L cell rows in angstrom, f fractional coordinates, E Green-Lagrange (G-L) strains, U = (I + 2E)^(1/2), J = det(I + 2E)^(1/2), S(E) = 1/2 ln(J^(-2/3) (I + 2E)), u displacements in angstrom): corrected structure L_hat = L U_hat, f_hat = f + u_hat L^-1, E_hat = (1/5) sum_r E_r volume change 100 (J_hat - 1) (%); shape change 100 |S(E_hat)|_F (%) spread s_S = ((1/5) sum_r |dev(E_r - E_hat)|_F^2)^(1/2), s_V = std_r tr E_r (%) domain lambda_min(I + 2E_hat) <= 1e-6: no cell has E_hat; the input is returned, flagged invalid lattice parameters a, b, c = |rows of L| (angstrom); alpha, beta, gamma the angles between them (degrees) Models: the networks from the Hugging Face repository utksi/recast-models (or a local release folder) and MACE-OMAT-0 from its official release (sha256 checked). Downloads are cached in RECAST_CACHE (default ~/.cache/recast) and the Hugging Face cache.

    (Z (n,), f (n x 3), L (3 x 3 rows, angstrom)); ValueError for a structure that cannot be corrected.

    given_request(path) ¶

    {'cell': L_c} or {'strain': ...} for recast.predict.given_strain.

    e.g. 'P6_3mc (186)'.

    correct(structure, source='dft', functional='PBE', given=None, symmetrize=0.0, out=None, release=None, mace=None, workdir=None, inputs='shipped', log=None) ¶

    Correct one calculated structure (a file path or ase.Atoms).

    source: dft (PBE or PBE+U relaxations) or the MLIP whose relaxations the structure comes from (tece_oam_rra, equflashv2_oam); functional: PBE or PBE+U (dft only); given: a given-cell request (dict, JSON file or structure file) at which the atoms are also placed; symmetrize: tolerance (angstrom) of the projection onto the input's space group, 0 for none; out: folder of the written files (none written when None); release, mace: local model paths (else downloaded); workdir: where the features are kept (a temporary folder when None); inputs: the featurizers (recast.featurizers.Inputs, or a spec of inputs_of), which must be those the release was trained with. Returns dict with Z, L, f, Lh, fh (the corrected structure), E (3 x 3 G-L strain), u (n x 3, angstrom), E_r (5 x 3 x 3), lam_min, invalid, the summary numbers, the given-cell structure (L_c, f_c) when asked, and the written files.

    summary_text(res) ¶

    Text summary of a correction.

    Table: the cell parameters (a, b, c in angstrom, alpha, beta, gamma in degrees, V in angstrom^3) of the calculated cell L, of the cell strained by each of the five estimates alone, L (I + 2E_r)^(1/2), and of the corrected cell L_hat, the relative change 100 (x_hat / x - 1) of each corrected parameter (%), and for every strain the volume change 100 (J - 1) and the shape change 100 |S(E)|_F (%). Below it: the space groups, the G-L strain of the correction (Voigt), the largest atomic displacement (angstrom) and the spread of the estimates (%).

    write_outputs(res, out) ¶

    Paths of the written files.

    recast.featurizers ¶

    SPDX-License-Identifier: MIT Utkarsh Singh: github.com/utksi

    Featurizers: the pretrained models that compute the inputs of the networks from a calculated structure, pluggable in the way ASE calculators are. A featurizer gives any of four inputs, and each input of a features folder may come from its own featurizer (Inputs): cell per-atom descriptors of the cell networks (estimators 1 to 5), when they differ from the atom ones atoms per-atom descriptors of the atom-fit networks (and of the cell networks when cell is None) hessian the Hessian H of the energy in Green-Lagrange (G-L) coordinates, stored as its retained modes H_ret relax the relaxation strains T1, T0, D = T1 - T0 (G-L) and their masks The networks of the paper read MACE-OMAT-0 for every input (SHIPPED: descriptors of every layer, the exact Hessian by automatic differentiation, the D3 relaxations); they expect exactly these. Another potential means retraining with the pipeline (recast.train).

    Conventions: Z atomic numbers, f fractional coordinates (n x 3), L cell rows (angstrom); coordinates q = (gamma, u), gamma = (E_11, E_22, E_33, 2 E_23, 2 E_13, 2 E_12) the engineering Voigt vector of the G-L strain E of the cell and u (n x 3) Cartesian displacements; the deformed structure has the cell L U and positions (r + u) U, U = (I + 2E)^(1/2).

    Mathematics (recast.features gives the details): H = d2W/dq2 at q = 0 = [[K, Lam^T], [Lam, Phi]] (eV, eV/angstrom, eV/angstrom^2), W the potential's energy: by automatic differentiation for MACE (recast.features.mace_hessian), else by central differences of the gradient g(q) of any ASE calculator (recast.features.hessian_fd: h = 1e-3 in gamma and 1e-3 angstrom in u) H_ret: the modes of the Kelvin-scaled S H S above 1e-3 eV/angstrom^2 (recast.features.retained) T1 = E(L, L_1), T0 = E(L, L_0), D = T1 - T0: G-L strains to the minima of the potential with (1) and without (0) the dispersion term (D3(BJ) by default), masks (c_1, c_0, c_1 c_0) (recast.features.relaxation_tensors) Contract of a featurizer (tests/test_featurizer_contract.py, recast.contract): under r -> r Q^T + t for any orthogonal Q (rotations and reflections) and translation t, the descriptors are unchanged and, in Kelvin-scaled strain coordinates, H -> R H R^T with R = diag(K, I_n kron Q), K the Kelvin representation of Q on symmetric strains.

    Featurizer ¶

    A source of inputs (module docstring). Subclasses give descriptors() and calculator(); the Hessian and the relaxations then follow by finite differences and ASE relaxations, unless a subclass overrides them.

    relaxations(Z, f, L) ¶

    Bases: Featurizer

    ASEFeaturizer ¶

    Bases: Featurizer

    Template for a new potential: any ASE calculator gives the Hessian (central differences of its G-L gradient) and the relaxations; descriptors come from a function of the structure.

    Example (EMT stands in for a machine-learned potential): from ase.calculators.emt import EMT feat = ASEFeaturizer(lambda precision: EMT(), radial_descriptors, name="emt", dispersion=None)

    calculator(precision='float64') ¶

    ASE calculator.

    descriptors(Z, f, L) ¶

    descriptors(Z, f, L) of the constructor.

    Inputs dataclass ¶

    The featurizer of each input of a features folder; None leaves that input out (cell: no desc_new.h5; relax: no tensors.npz).

    names() ¶

    Names of the four inputs (None for an input left out).

    identity(path, known, digest, prefix) ¶

    Name recorded in features.json for the model file at path.

    radial_descriptors(Z, f, L, rc=5.0, nb=8) ¶

    Per-atom radial descriptors (n x (1 + 2 nb)) for the template and the tests: invariant under rotations, reflections, translations and the choice of periodic images; no pretrained model.

    shipped_inputs(mace_model, device='cpu') ¶

    Inputs of the released networks.

    write_features(structures, out, inputs, log=None, resume=False) ¶

    Compute and store the inputs of calculated structures (dicts key, Z, f, L, functional); returns the folder.

    The layout is that of recast.features.load_new, which recast.predict and recast.train read. Every structure is written to train.h5 and its pair list, relaxation record and cell descriptors to partial.h5, with the attribute done set last; resume = True keeps every structure already done and recomputes any other. When all structures are done, pairs.npz, tensors.npz, d3.jsonl, desc_new.h5 and features.json are written in the order of structures and partial.h5 is removed. The folder is the same as that of one uninterrupted run.

    merge_features(folders, out, order) ¶

    Copy the train.h5 groups of every folder into out/train.h5 and write pairs.npz, tensors.npz, d3.jsonl, desc_new.h5 and features.json for the structures in order; returns out.

    The folders must name the same featurizers (features.json), hold disjoint structures, and together exactly the structures of order; the result equals the folder of one run over order.

    check_inputs(manifest, folder) ¶

    Raise ValueError if features.json of the folder names other featurizers than the release was trained with; a folder without features.json (written before it existed) is not checked.

    recast.esen ¶

    SPDX-License-Identifier: MIT Utkarsh Singh: github.com/utksi

    eSEN-30M-OMat (fairchem-core 1.10.0: esen_backbone with the esen_mlp_efs_head_dens energy head) in plain PyTorch, read from the official checkpoint file esen_30m_omat.pt (gated repository facebook/OMAT24; its licence applies, and no weight is copied into this package). It gives the descriptors of the eSEN variant of the cell networks (the released networks do not use them), and energies, forces, stresses and the Hessian, without fairchem.

    Conventions: positions r_k (n x 3, angstrom), cell rows L (3 x 3, angstrom), Z atomic numbers; edge e = (s_e -> t_e) with integer image shift m_e, s the neighbour and t the centre (fairchem's radius_graph_pbc order). Constants of the checkpoint: C = 128 channels, lmax = 3, mmax = 2, 10 blocks, cutoff r_c = 6 angstrom, 64 Gaussians, at most 300 neighbours per atom.

    Mathematics

    Input features of the correction, every one computed from the calculated structure alone (no experimental quantity): the MACE-OMAT-0 Hessian in Green-Lagrange (G-L) coordinates, the pairs within the cutoff and the structure's own first-shell bonds, the two D3 relaxation strains, and the per-atom descriptors of MACE-OMAT-0 (and, for training other variants, of eSEN-30M-OMat). write_features() (and recast.featurizers.write_features for any choice of models) stores them in a folder; load_new() reads the folder into the inputs of the predictors. esen_calculator(), esen_descriptors() and write_esen_descriptors() are the fairchem path, kept as the reference of recast.esen (they need fairchem-core 1.10).

    Mathematics

    Coordinates q = (gamma, u) (6 + 3n): gamma the G-L strain of the cell, u (n x 3) Cartesian displacements, flattened atom-major.     recast.geometry ¶

    SPDX-License-Identifier: MIT Utkarsh Singh: github.com/utksi

    Geometry of crystal structures used by the correction: cells, fractional coordinates, the Green-Lagrange strain between two cells and its volume and shape readouts, engineering Voigt vectors and first-shell bonds.

    Conventions

    L cell matrix (3 x 3, angstrom); its rows are the lattice vectors a_1, a_2, a_3 f fractional coordinates (n x 3); Cartesian positions r = f L (angstrom) G metric tensor G = L L^T (angstrom^2); cell volume V = |det L| (angstrom^3)

    Mathematics

    Green-Lagrange (G-L) strain from a reference cell L_ref to a target cell L_tgt, in the Cartesian frame of L_ref: C = L_ref^-1 G_tgt L_ref^-T = I + 2E, E = 1/2 (C - I). C is the right Cauchy-Green tensor: if L_tgt = L_ref U R with U symmetric positive definite and R orthogonal, then C = U^2, so the stretch U = (I + 2E)^(1/2) rebuilds the target, L_tgt = L_ref U R. A strain E is admissible when lambda_min(I + 2E) > LAM_MIN = 1e-6; otherwise no cell has it. Volume and shape of E (the paper's error measures read these; they do not depend on the strain measure): J = det(I + 2E)^(1/2) = V_tgt / V_ref, S(E) = 1/2 ln(J^(-2/3) (I + 2E)) (symmetric, traceless). Engineering Voigt vector of a symmetric strain: gamma(E) = (E_11, E_22, E_33, 2 E_23, 2 E_13, 2 E_12). First-shell bonds of atom i: every pair (j, image n) with d_ijn = |(f_j + n - f_i) L| <= 1.15 min_{(j', n') != (i, 0)} d_ij'n', searched over the images n of a box sized for a radius r_max = 4.5 angstrom. The shell is that of atom i, so the list is not symmetric in i and j in general. Unwrapping: each fractional position is moved to the periodic image nearest a reference position, f <- f_ref + (f - f_ref) - round(f - f_ref).

    Targets of a structure pair: the Green-Lagrange (G-L) strain E and the displacements u_k that carry a calculated structure (a DFT or MLIP relaxation) onto the experimental one, with the checks that decide in which description of the experimental structure the target is taken and whether the displacement target is usable.

    Conventions (as geometry.py): L cell rows (angstrom), f fractional coordinates (n x 3), Z atomic numbers. The two structures list the same atoms in the same order (as in the paper's matched pairs; the checks below decide whether the displacement target is usable).

    Mathematics

    Unwrapping: the calculated coordinates are moved to the periodic images nearest the experimental ones, f_c <- f_e + (f_c - f_e) - round(f_c - f_e). Changes of basis: the set UNI of integer matrices M with entries in {-1, 0, 1} and |det M| = 1, in the order of itertools.product((-1, 0, 1), repeat=9) (the identity is one of them, index IDENT). The experimental cell in basis M is M L_e (rows), with fractional coordinates f_e M^-1. Strain norm of basis M (the distance between the two cells that decides the basis): with lam_i the eigenvalues of L_c^-1 (M G_e M^T) L_c^-T (G_e = L_e L_e^T), the norm of the log stretch, |eps_M|_F = sqrt(1/4 sum_i (ln lam_i)^2). Displacements of the stored correspondence: du_k = f_c,k - f_e,k, t = mean_k du_k (mean translation), disp_k = |(du_k - t) L_c|, rms_id = sqrt(mean_k disp_k^2) (angstrom). Swapped atoms: an atom whose nearest same-species experimental site (minimum image over the 27 neighbouring images, after removing t) is not its own. Flag (the description is checked further): |eps_M|_F < 0.99 |eps_I|_F for some M != I, or a swapped atom, or max_k disp_k > 0.5 angstrom. For a flagged pair (variants): best_match(f_m) = min over origins t (anchored on the rarest species) and same-species assignments (Hungarian algorithm on the minimum-image distances) of sqrt(mean_k |(f_c,k - f_m,pi(k) - t) L_c|^2), with one re-centring of t on the matched sites; rms_perm = best_match(f_e); candidates: the 24 bases with the smallest |eps_M|_F among those below 0.99 |eps_I|_F; for each, rms_M = best_match(f_e M^-1 mod 1); the basis k_alt with the smallest rms_M (first in order on ties). Strain target: E = green(L_c, L_e) = 1/2 (L_c^-1 G_e L_c^-T - I) (geometry.green), and r = rms_id; for a flagged pair r = min(r, rms_perm), and if a candidate exists and rms_alt < r - 0.02 or (rms_alt <= r + 0.02 and |eps_alt|_F < |eps_I|_F): E = green(L_c, UNI[k_alt] L_e), r = rms_alt, alt = True. The pair is rearranged when r > 0.3 angstrom. Displacement target, in the frame of the calculated cell (stored basis and atom order): u_k = (f_e,k - f_c,k) L_c - mean_k (f_e,k - f_c,k) L_c (angstrom), usable (pos_ok) when alt is False, sqrt(mean_k |u_k|^2) <= 0.3 angstrom and no atom other than H moves more than 1 angstrom. Target vector q = (gamma(E), u*) in R^(6 + 3n), gamma the engineering Voigt vector.

    strain_norms(L_ref, L_tgt) ¶

    Frobenius norms (len(UNI),) of the log stretches from L_ref to M L_tgt for every change of basis M in UNI.

    lam_i are the eigenvalues of L_ref^-1 (M L_tgt L_tgt^T M^T) L_ref^-T; |eps|_F = sqrt(sum_i (ln lam_i / 2)^2).

    rms_identity(L, f_e, f_c) ¶

    Root-mean-square displacement (angstrom) of the stored correspondence, the mean translation removed.

    du_k = f_c,k - f_e,k (fractional), Cartesian through the cell L (rows); the mean over the atoms is removed first.

    sites(L, Z, f_e, f_c) ¶

    Site checks of the stored correspondence: (max_k disp_k, |t L|, number of swapped atoms, max own / other).

    t = mean_k (f_c,k - f_e,k) is the mean translation (fractional); disp_k = |(f_c,k - f_e,k - t) L| (angstrom). For each species with two or more atoms, the minimum-image distance (27 neighbouring images) of every calculated site, shifted by -t, to every experimental site of that species: an atom is swapped when another site is nearer than its own; worst is the largest ratio of the own distance to the nearest other one.

    mindist(L, f_a, f_b) ¶

    Minimum-image distances (angstrom) between every site of f_a (n_a x 3) and every site of f_b (n_b x 3).

    best_match(L, Z, f_c, f_m) ¶

    Smallest root-mean-square displacement (angstrom) between two descriptions of a structure in the cell L.

    Origins: t = f_c,a0 - f_m,j for the first atom a0 of the rarest species and every atom j of that species. For each origin, per species the assignment that minimizes the summed squared minimum-image distances is found with the Hungarian algorithm; t is then shifted by the mean residual of the matched sites and the assignment repeated once.

    recast.fits ¶

    SPDX-License-Identifier: MIT Utkarsh Singh: github.com/utksi

    Least-squares fits that turn predicted pair-length changes into a deformation of the structure: the distance least-squares (DLS) fit and the Hessian-regularized DLS fit, batched over structures (torch, float64).

    Coordinates of a structure with n atoms: q = (gamma, u) in R^(6 + 3n), with gamma the engineering Voigt vector of the Green-Lagrange (G-L) strain E of the cell and u the Cartesian displacements (angstrom) in the frame of the calculated structure. A batch pads every structure to M = 6 + 3 n_max coordinates; padded coordinates get identity rows and a zero right-hand side.

    Mathematics

    Pair p = (i, j, image) with vector v_p (angstrom), length d_p = |v_p|, direction r_hat_p = v_p / d_p. Green strain of its length under q, g_p = (d'_p^2 / d_p^2 - 1) / 2, to first order (exact at u = 0): a_p . q = r_hat_p^T E r_hat_p + r_hat_p . (u_j - u_i) / d_p, r_hat^T E r_hat = c_p . gamma, c_p = (x^2, y^2, z^2, yz, xz, xy) for r_hat = (x, y, z). Normal equations of the predicted changes s_p with weights w_p: A = sum_p w_p a_p a_p^T, r = sum_p w_p s_p a_p. Relative regularization (scale-free, so that a supercell gets the same fit): lam_g = LG sum_p w_p on gamma, in the Frobenius metric RG = diag(1, 1, 1, 1/2, 1/2, 1/2) lam_u = LU * 2 sum_p (w_p / d_p^2) / (3n) on u (the mean diagonal of A_uu, self-image pairs counted) DLS fit: (A + Lam) q_hat = r DLS fit of the cell (affine): (A_gg + lam_g RG) gamma_hat = r_g, u_hat = 0 Hessian-regularized DLS fit: q_hat = argmin_q 1/2 q^T H q + Delta E(q) + regularization (H: the retained-mode G-L Hessian H_ret of recast.features, float64), Delta E(q) = kappa_0 / 2 sum_p w_p (a_p . q - s_p)^2 (the missing energy; spring constants kappa_0 w_p), so that (P H P + kappa_0 A + Lam) q_hat = kappa_0 r, with Lam computed from the spring constants kappa_0 w_p and P = I - E E^T removing the three rigid translations E = (0_6; 1_n kron I_3) / sqrt(n) from the Hessian H. Limits: kappa_0 -> infinity gives the DLS fit; small kappa_0 gives the linear response kappa_0 H^+ r. Fit at a given cell gamma_c: u_hat = (A_uu + lam_u I)^-1 (r_u - A_ug gamma_c). Solves: M x = r by LU, accepted when |M x - r|_2 <= 1e-10 sqrt(m) (|M|_inf |x|_inf + |r|_inf) per system, else repeated on the CPU (and checked again). Gradients: dx = M^-1 (dr - dM x), so grad_r = M^-1 g, grad_M = -grad_r x^T.

    recast.losses ¶

    SPDX-License-Identifier: MIT Utkarsh Singh: github.com/utksi

    Training losses of the correction: the cell loss of a predicted Green-Lagrange (G-L) strain, which is the loss of the paper's own volume and shape errors, and the atom loss of predicted displacements; both robust (pseudo-Huber) and averaged over the structures of a batch (torch).

    Mathematics (E: G-L strain, 3 x 3, symmetric, in the frame of the calculated cell; C = I + 2E; gamma(E) its engineering Voigt vector): Pseudo-Huber function of a squared residual x^2 (quadratic below delta, linear above): rho_delta(x^2) = delta^2 (sqrt(1 + x^2 / delta^2) - 1). Volume and shape of E: ln J = 1/2 ln det C (ln of the volume ratio), S(E) = 1/2 ln(J^(-2/3) C) (traceless). Cell loss of a prediction E_hat with target E (w0 weights the volume part; every rotation-invariant quadratic form of a symmetric error combines a traceless and a scalar part, Schur's lemma, so one weight sets the balance): s2 = |S(E_hat) - S(E)|_F^2, t2 = w0 (ln J(E_hat) - ln J(E))^2 / 3, joint rho_delta(s2 + t2), decoupled rho_delta(s2) + rho_delta(t2). Evaluation in float64 without an eigendecomposition (finite gradients at degenerate eigenvalues; 3 x 3 determinants and inverses by cofactors): Cbar = J^(-2/3) C, Y = (Cbar - I)(Cbar + I)^-1 = tanh(S) (Cayley transform, symmetric), S = atanh(Y) = sum_{k=0}^{K-1} Y^(2k+1) / (2k+1) + R_K, |R_K|_F <= r^(2K+1) / ((2K+1)(1 - r^2)) if |Y|_F <= r; with |Y|_F <= R0 = 1/2 and K = 24 terms, |R_K|_F <= 4.8e-17. For |Y|_F > R0 (shapes far beyond the data): S = 2^j atanh(Y_j), Y_j the Cayley transform of Cbar^(1/2^j) (j square roots by the coupled Denman-Beavers iteration, each renormalized to det 1), j the smallest count with |Y_j|_F <= R0. With the atoms solved at the experimental cell (gamma = gamma), L_g = 0 and the joint atom loss is rho_delta(wb L_b + wu sum um (u_hat - u)^2), equation (lossat) of the paper's Methods.     variant errors of a deformation q (percent): vol 100 |J / J - 1| axis 100 (1/3) sum_i |ln(|a_i U| / |a_i U|)|, a_i the rows of L bond, bondXH, angle, disp recast.errors.atom_errors (only when the displacement target is usable) cell errors of a predicted strain (recast.errors.cell_errors): cell:vol, cell:shape, cell:len in percent and cell:ang in degrees; the same for E = 0: PBE:vol_cell, PBE:shape, PBE:len, PBE:ang variants of a test structure: PBE (q = 0), cellO (gamma, u = 0), full (gamma_hat, u_hat(gamma_hat)), cellO+final (gamma, u_hat(gamma*)), gamma_hat = gamma(E_hat) summary over partitions k = 1..K with scored test sets T_k (excluded structures left out): m_k(x) = mean over T_k of x (missing values skipped); mean = (1/K) sum_k m_k; sd = sample standard deviation of the m_k (ddof 1); the median over all scored rows; bands of the uncorrected shape error PBE:shape (< 1, 1 to 3, >= 3 %) with the means of cell:shape, PBE:shape and cell:vol; bonds to H over the neutron rows corrected resampled t-test (Nadeau and Bengio 2003) of fold mean differences d_j, j = 1..J, test and training sizes n2, n1: t = dbar / sqrt((1/J + n2/n1) s_d^2) with J - 1 degrees of freedom; two-sided p = 2 P(T > |t|), one-sided p = P(T > t) for an increase cluster bootstrap over groups g (S_c(g), S_r(g) the sums of corrected and reference errors of the structures in g, n(g) their number): B draws of G groups with replacement (counts w_b(g)), d_b = sum_g w_b (S_c - S_r) / sum_g w_b n, r_b = 100 (sum_g w_b S_c / sum_g w_b S_r - 1), 95 % intervals from the 2.5 and 97.5 percentiles over b; B = 10,000, numpy default_rng(20261028)

    usage: python -m recast.score --data DIR --pred DIR --keys 42,43 --out FILE.json (pred_.npz of recast.train: keys, E, u_free, u_cellO; DIR the training folder with the targets)

    recast.pipeline ¶

    SPDX-License-Identifier: MIT Utkarsh Singh: github.com/utksi

    The training pipeline from structure pairs to a release, as functions behind the recast commands: targets pairs (calculated and experimental structure, same atoms in the same order) -> targets.h5 (recast.targets) features targets.h5 -> a training folder: the inputs of the calculated structures (recast.featurizers) with the targets; optionally one shard of the structures (index i mod n = I), resumable, and the merge of the shards into one folder (the same folder as one run) split partitions {key: {train, val, test}} (recast.partitions) members the 18 members of every key: six member types (recast.train presets) times three initializations jobs the same training as one command line per member type, initialization and key (for a job array) select the candidate run with the lowest development error (one metric for all candidates) export trained members -> a release folder (manifest.json, members/), the input of recast.predict score the release's test errors on each key's own test set (recast.score)

    Conventions as recast.targets and recast.train (L cell rows in angstrom, f fractional coordinates, q = (gamma, u) with gamma the engineering Voigt vector of the Green-Lagrange strain E and u the displacements in angstrom).

    Mathematics

    shards shard I of n holds the training structures (sorted keys of targets.h5, rearranged pairs left out) of index i with i mod n = I; the merge restores that sorted order partitions recast.partitions (test splits, development folds, grouped folds, fractions) selection J(c) = (1/K) sum_k mean over the test structures of key k of the metric of candidate c (for example cell:shape = 100 e_S of the cell, or cellO+final:bond = 100 e_B of the atoms at the experimental cell); the chosen candidate minimizes J, ties to the first listed ensemble per key k: E_hat = (1/15) sum over the cell members of key k of E_m, u_hat the mean of the three atom-fit members' atoms at gamma(E_hat), u_c their atoms at the experimental cell gamma* (recast.predict with keys = [k]); errors recast.score.structure_row, summary recast.score.summarize

    recast.toy ¶

    SPDX-License-Identifier: MIT Utkarsh Singh: github.com/utksi

    A small synthetic set of structure pairs for the tutorial and the pipeline test: ASE prototypes of seven metals and their alloys as the calculated structures, each deformed by a known strain and known displacements as its experimental structure, and toy featurizers (ASE's EMT potential, radial descriptors). No external data; the numbers mean nothing physical.

    Conventions: L cell rows (angstrom), f fractional coordinates (n x 3); r = f L.

    Mathematics

    calculated L_c, f_c of an ASE prototype (fcc, bcc, hcp, B2, L1_2, L1_0) at lattice constants that give every atom the volume v(Z) of its fcc reference state (ASE's reference data) strain E = (e_V / 3) I + e_S (3 z z^T - I) / 2 (a Green-Lagrange strain), z = the unit vector along the third cell row, e_V = -(1/n) sum_k c(Z_k) (the volume change, c(Z) = 0.010 to 0.045 per element), e_S = 0.004 for the hexagonal and tetragonal cells, else 0 displacements u_k drawn from N(0, (0.01 angstrom)^2) per component (seeded by the structure index), the mean removed: u_k <- u_k - (1/n) sum_l u_l; none for one-atom cells experimental L_e = L_c U, f_e = f_c + u L_c^-1, so that r_e,k = (r_c,k + u_k) U, U = (I + 2E*)^(1/2)

    recast.cli ¶

    SPDX-License-Identifier: MIT Utkarsh Singh: github.com/utksi

    The recast command. recast correct corrects one calculated structure with the released networks; the other subcommands run the training pipeline (recast.pipeline) and pass their options on to recast.train, recast.predict and recast.score. No mathematics of its own: each subcommand calls the function named in its help.

    usage:

    recast correct STRUCTURE [--source dft|tece_oam_rra|equflashv2_oam] [--functional PBE|PBE+U] [--given FILE]
               [--symmetrize TOL] -o OUT
recast toy -o pairs.json
recast targets PAIRS.json -o targets.h5
recast features targets.h5 -o DATA [--inputs shipped|toy|MODULE:FUNCTION] [--device cuda] [--shard I/N] [--resume]

recast split DATA -o parts.json [--keys 42,...,51] [--test 0.1] [--val 0.1] [--order FILE] [--units FILE]
recast folds --partitions parts.json --groups groups.csv -o folds.json [--random 3000,3010] [--formula 3100]
             [--prototype 3200] [--seed 20261022] [--units FILE] [--add-to FOLDS]
recast grouped DATA --groups groups.csv -o grouped.json [--prototype 4200] [--chemsys 4300] [--units FILE]
recast fraction parts.json -o frac.json --fraction 0.25 [--seed 0] [--keys K,...]
